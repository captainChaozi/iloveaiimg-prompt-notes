# Credit math for ILoveAIImg models

Reference numbers for [ILoveAIImg](https://iloveaiimg.com/) as shown in the generator and on the [pricing page](https://iloveaiimg.com/pricing). The credit quote beside Create is always the final word; it changes with model and settings.

## Credits per run (as quoted)

| Model | Credits | Output |
|---|---|---|
| GPT Image 2.5 | 2 (at 1K) | 1K / 2K / 4K, ratios 1:1 to 21:9 |
| FLUX 3 Image Klein | 3 | 1K / 2K / 4K, up to 10 references |
| Seedream 5.0 Pro | 17 | 1K / 2K |

## Plans

| Plan | Price | Credits |
|---|---|---|
| Free | $0 | 6 per day (up to 3 images); expire daily; images kept 7 days |
| Pro | $20 / month (yearly: $10 / month, $120 / year) | 1,000 per month |
| Max | $80 / month | 5,000 per month |
| Pack | $29.90 one-time | 1,500 (up to 750 images) |
| Pack | $49.90 one-time | 3,000 |

## Worked examples

- 1,500-credit pack ÷ 2 = 750 GPT Image 2.5 runs at 1K, or 500 FLUX 3 Image Klein runs, or 88 Seedream 5.0 Pro runs.
- One Seedream 5.0 Pro run (17) ≈ 8.5 GPT Image 2.5 runs.
- Free daily allowance (6) = 3 GPT Image 2.5 runs or 2 FLUX runs.

## Tip

Draft with the cheaper model, then spend expensive credits on the final brief.
