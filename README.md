# ILoveAIImg prompt notes

Prompt patterns for [ILoveAIImg](https://iloveaiimg.com/), a set of free AI image tools to create pictures, edit photos and remove backgrounds.

## Which tool

| Goal | Tool |
|---|---|
| New picture from words | [Text to image](https://iloveaiimg.com/text-to-image-free) |
| Variation of an existing picture | [Image to image](https://iloveaiimg.com/image-to-image) |
| Change one thing, keep the rest | [AI image editor](https://iloveaiimg.com/ai-image-editor) |
| Transparent PNG cutout | [Background remover](https://iloveaiimg.com/free-remove-background) |

## Patterns

- **Edit:** "Change *X* to *Y*. Keep *subject, colour, angle*."
- **Poster:** state the exact headline, the hierarchy (headline top, focal image centre), lighting and margins.
- **References:** give each uploaded image one job ("image 1 = product to keep, image 2 = palette").
- Draft at 1K; re-run the winner at 2K or 4K.

## Models

FLUX 3 Image Klein, GPT Image 2.5, GPT Image 2, Nano Banana Pro, Seedream 5.0 Pro, Nano Banana 2 and others; compare them on [image models](https://iloveaiimg.com/ai-image-models).
