# ILoveAIImg: one-sentence edit habit

Site: https://iloveaiimg.com/

## Pattern
Upload → write **one** concrete change (subject + style + what must stay) → preview → download.

Tools:
- Effects gallery: https://iloveaiimg.com/ai-image-effects
- Image to image: https://iloveaiimg.com/image-to-image
- Pricing: https://iloveaiimg.com/pricing

Avoid stacking five adjectives in the first pass; iterate after you see the preview.
