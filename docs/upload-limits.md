# 上传与参考图限制速查（Upload limits）

> 依据 [ILoveAIImg](https://iloveaiimg.com/) 公开的 [模型页](https://iloveaiimg.com/ai-image-models) 与生成器界面整理，2026-11-03 核对。数值可能调整，以站内为准。

## 通用限制

| 项目 | 限制 |
|---|---|
| 支持格式 | PNG、JPG、WebP |
| 单张大小 | ≤ 10 MB |
| 提示词长度 | ≤ 4,000 字符 |
| 素材来源 | 本地上传，或从 Assets 选择 |

| Nano Banana | 14 | 1K · 3 credits |

## 上传失败时先查

1. 格式是否为 PNG/JPG/WebP（HEIC 需先转换）。
2. 是否超过 10 MB。
3. 参考图数量是否超过所选模型上限；换模型时上限会变。
